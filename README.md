# FetusCountVisualPatch

FetusCountVisualPatch is a mod for **Monster Black Market** —— adds status icons for pregnancy counts 4 and 5, and allows setting the upper limit on the Max Concurrent Fetuses.

### Features

* Status icons for pregnancy counts 4 and 5.
* Set the upper limit on the Max Concurrent Fetuses.

### Requirements

| Dependency           | Version |
| -------------------- | ------- |
| MBM.ModLoader        | latest  |
| Monster Black Market | latest  |
