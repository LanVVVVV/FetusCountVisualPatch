# FetusCountVisualPatch

FetusCountVisualPatch is a mod for **Monster Black Market** —— Adds status icons for pregnancy counts 4 and 5, and allows setting the upper limit on the Max Concurrent Fetuses. This mod is specifically designed for ComplexBreeding's larger Max Concurrent Fetuses.

### Features

* Status icons for pregnancy counts 4 and 5.
* Set the upper limit on the Max Concurrent Fetuses.
* When Max Concurrent Fetuses is set to 5, allows two large monster fetuses simultaneously.
